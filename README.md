    <h1> Railway Reservation System </h1>
  </hr>
    <ul>
      <li><h2> Project description </h2></li>
    </hr>
      <p>Railway Reservation System is a simple C++ based project used to manage train records. It allows the user to add new train details, display all available trains, and search for a particular train using its train number. The project is made using Object-Oriented Programming (OOP) concepts such as classes, objects, constructors, destructors, static data members, private data members, and member functions.</p>
    </hr>
      <li><h2>What is included in this project? </h2></li>
    </hr>
      <ul>
        <li>Add New Train Record</li>
        <li>Display All Train Records</li>
        <li>Search Train by Number</li>
        <li>Train Count</li>
        <li>Menu-Driven System</li>
        <li>Maximum 100 Records</li>
      </ul>
    </hr>
      <li><h2>How this project is made? </h2></li>
    </hr>
      <p>The project is mainly divided into two classes: Train and RailwaySystem. The Train class stores the details of one train, such as train number, train name, source, destination, and train time. It contains functions to input, display, and modify train information. A static variable trainCount is used to count train records. The RailwaySystem class manages multiple train objects. It stores up to 100 trains in an array and provides functions to add a train, display all trains, and search for a train by its number. Finally, the main() function provides a menu to the user. The user selects an option, and the corresponding function of the RailwaySystem class is called. The menu continues until the user selects Exit.</p>
